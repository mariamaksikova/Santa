# 🎅 Secret Santa - Тайный Санта

Веб-приложение для организации игры "Тайный Санта" на C++.

## 📋 Требования

- Компилятор C++17 (g++ или clang++)
- SQLite3 библиотека
- macOS/Linux

## 🔨 Сборка проекта

### Способ 1: Использование скрипта сборки (рекомендуется)

```bash
./build.sh
```

### Способ 2: Использование CMake

```bash
mkdir -p build
cd build
cmake ..
make
cd ..
```

### Способ 3: Прямая компиляция

```bash
g++ -std=c++17 -Wall -Wextra -O2 main.cpp -o santa -lsqlite3 -pthread
```

## 🚀 Запуск

После успешной сборки запустите сервер:

```bash
./santa
```

Сервер будет доступен по адресу: **http://localhost:8080**

## 📝 Использование

1. Откройте браузер и перейдите на http://localhost:8080
2. Создайте игру, указав название, бюджет и максимальное количество участников
3. Поделитесь ссылкой-приглашением с друзьями
4. После регистрации все участники автоматически попадут в комнату
5. Когда наберётся нужное количество участников, автоматически запустится рандомайзер
6. Каждый участник увидит, кому он должен подарить подарок

## 🎨 Особенности

- ✨ Красивый новогодний дизайн с анимированными снежинками
- 🎅 Анимированная иконка Санты
- 🔴 Красный фон в новогоднем стиле
- ⚪ Белые кнопки
- 📱 Адаптивный дизайн для мобильных устройств

## 🗄️ База данных

База данных SQLite создаётся автоматически в файле `santa.db` при первом запуске.

## 🛠️ Пересборка

Если нужно пересобрать проект после изменений:

```bash
# Удалите старый исполняемый файл и соберите заново
rm -f santa
./build.sh
```

Или просто запустите скрипт сборки снова - он сам удалит старый файл.
